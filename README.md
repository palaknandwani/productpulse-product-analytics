
# ProductPulse 📊

### Product Analytics & Decision Intelligence Platform

ProductPulse is a dashboard designed to help product managers understand user engagement, feature adoption, customer feedback and product performance.

## Features
- KPI Dashboard
- User Analytics
- Feature Performance
- Customer Insights
- RICE Feature Prioritisation

## Technology Stack
- Python
- Pandas
- Streamlit
- Plotly

## Installation

1. Clone this repository.
2. Install dependencies:

pip install -r requirements.txt

3. Run the application:

streamlit run app.py

## Data Disclaimer

This initial version uses synthetic demonstration data.
